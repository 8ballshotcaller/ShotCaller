# ShotCaller

Shot Caller is a browser-based pool shot-calling tool designed to help players quickly identify and visualize possible shots during a game.

What It Does

Shot Caller lets you set up the table and generate a recommendation based on the balls in play.

You can select:

* Cue ball
* Object/target ball
* Pocket
* Shot type
* Rail
* Speed
* Ball roles

The available shot types include:

* Straight
* Cut
* Combo
* Bank
* Kick

You can also assign balls as:

* Target Ball
* Player’s Ball
* Opponent’s Ball

Opponent balls can be used as blockers, while a player’s balls can be used when setting up combination shots.

How It Works

1. Place the cue ball and target ball.
2. Select the desired pocket.
3. Choose or use the suggested shot type.
4. Configure additional shot details when applicable.
5. Use the generated call to help plan the shot.

The interface is designed to keep the information focused on the shot rather than requiring a complicated setup.

Shot Types

Straight

A direct shot from the cue ball to the target ball and pocket.

Cut

A shot where the cue ball contacts the target ball at an angle to send it toward the pocket.

Combo

A combination shot where one ball is used to contact another ball before the intended target reaches the pocket.

Bank

A shot where the object ball is played off a rail before reaching the pocket.

Kick

A shot where the cue ball contacts a rail before making contact with the target ball.

Technology

Shot Caller is a client-side web application built to run directly in the browser.

No installation is required.
